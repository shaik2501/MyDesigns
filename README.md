# MyDesigns

My personal, open-source collection of reusable design references and structured design prompts.

Each folder represents a different website or visual style. It contains:

- A `DESIGN.md` blueprint documenting the colors, typography, spacing, layout, components, imagery, responsive behavior, and interaction patterns.
- A reference image showing the complete visual design.

## Repository structure

```text
MyDesigns/
├── README.md

│   └── iqoo_design_image.png
├── healthathon/
```

New designs will be added as separate folders so this repository can grow into a practical visual library for future projects.

The documented design systems are shared for learning and inspiration. Referenced brand names, trademarks, and source images remain the property of their respective owners.
