# MyDesigns

My personal, open-source collection of reusable design references and structured design prompts.

Each folder represents a different website or visual style. It contains:

- A `DESIGN.md` blueprint documenting the colors, typography, spacing, layout, components, imagery, responsive behavior, and interaction patterns.
- A reference image showing the complete visual design.
- A `pages/` gallery when the source has distinct core public or authentication pages.
