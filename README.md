# iQOO TechQuest Design Blueprint

A reusable design-system prompt and visual reference distilled from the live [TechQuest / iQOO Z Series event page](https://techquest.reskilll.com/).

## Included design

- [`techquest-reskilll-iqoo-z-series/DESIGN.md`](techquest-reskilll-iqoo-z-series/DESIGN.md) — implementation-ready design language, tokens, layout rules, responsive behavior, motion, accessibility, and a copy-ready master prompt.
- [`techquest-reskilll-iqoo-z-series/iqoo_design_image.png`](techquest-reskilll-iqoo-z-series/iqoo_design_image.png) — full-page visual reference supplied with the brief.

## How to use

Give `DESIGN.md` to your coding or design assistant together with your new product's content and functional requirements. Tell it to use the file as the visual authority while adapting brand names, copy, and imagery to your project.
